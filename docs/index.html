🥑AvocadoMTP

Android phones in the macOS Finder, over USB

macOS has no MTP stack, so it can't see Android phones. AvocadoMTP speaks MTP itself over libusb, and a small background daemon mounts each phone storage as its own disk through FUSE-T.

Lazy write staging

FUSE-T's FSKit backend opens every file read-write. Files are now only copied to the Mac for editing when the first write actually arrives, not on every open.

Adaptive read-ahead

Starts at 128 KiB and doubles while reads stay sequential, up to 8 MiB. Thumbnails stay small; big copies get big blocks. Buffers are pooled.

Hotplug, not polling

The daemon sleeps until a USB device arrives or leaves. No traffic to an idle phone, so its MTP service can sleep too.

Quick start

macOS 14 or later, Apple Silicon or Intel. No Xcode, Go or libusb needed.

One command: the menu bar app, the service and Finder volumes

curl -fsSL https://raw.githubusercontent.com/andymartinezot/avocadomtp/main/install.sh | bash

Downloads the latest release, checks its sha256, installs FUSE-T (with Homebrew if you have it), puts AvocadoMTP.app in /Applications and starts the service. Run it again to update.

From source

git clone https://github.com/andymartinezot/avocadomtp.git && cd avocadomtp
./install.sh --from-source          # service, volumes and CLI (Homebrew)
scripts/build-app.sh                # or build the app yourself (Xcode, ad-hoc signed)

The app carries the service inside, updates it when the app is newer, and shows what's missing (FUSE-T, the FSKit toggle).

Then turn on System Settings → General → Login Items & Extensions → File System Extensions → fuse-t, unlock the phone and choose File transfer.
